Each skill lives in its own sub-directory under `.agents/skills/<skill>/` and follows a uniform layout: a `SKILL.md` containing YAML frontmatter (`name`, `description`, optional `disable-model-invocation`) plus the procedural instructions the model executes; an optional `agents/openai.yaml` declaring `interface.display_name`, `short_description`, and `policy.allow_implicit_invocation`; and optional supporting docs or scripts. The `ask-matt/SKILL.md` acts as the central router, defining the main idea→ship flow, on-ramps (triage, diagnosing-bugs, wayfinder), vocabulary layer (domain-modeling, codebase-design), and standalone skills, so other skills reference each other by path like `/grill-with-docs`, `/implement`, `/tdd`. Some skills ship executable artifacts — `wizard/template.sh` is a generated bash wizard with a shared library + authorable STAGES section, and `diagnosing-bugs/scripts/hitl-loop.template.sh` is a human-in-the-loop reproduction template. Dependency direction is one-way: skills are invoked by name from the router or from AGENTS.md pointers; there is no runtime framework, just Markdown consumed by the agent platform.
