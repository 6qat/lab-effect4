Root `package.json` declares a Bun workspaces setup (`packages/*`) so the two code children — `packages/lab` (Effect v4 learning examples) and `packages/tcp` (typed TCP client) — are installed and versioned together. The root `tsconfig.json` extends `tsconfig.base.json` and explicitly includes only `packages/lab/src/**/*.ts` and `packages/tcp/src/**/*.ts`, making TypeScript compilation a workspace-wide gate. Root-level scripts (`test`, `typecheck`, `format`, `format:check`) delegate to every child via `bun run --workspaces <script>`, while `biome lint .` runs once at the root against all packages. `docker-compose.yml` spins up Redis for the lab's job-queue experiments. Cross-cutting concerns live outside the code children: `.github/` holds the CI pipeline, `.kilo/` configures Kilo AI, `.zed/` is synced from `docs_and_research` via `scripts/sync-zed-prompts.mjs`, and `.agents/` consumes the Markdown skills from `agent_skills`. The `overrides` field pins `@effect/platform-node-shared` to `4.0.0-rc.112` across the whole workspace to keep the two packages on the same Effect v4 release candidate.
