Flat collection of self-contained `.ts` example scripts under `src/`, each demonstrating one topic: I/O and error handling (`creating-effects.ts`, `error-channel-operations.ts`, `result.ts`), service injection (`default-services.ts`), control-flow variants (`control-flow-*.ts`), concurrency primitives (`concurrency-deferred.ts`, `concurrency-pubsub.ts`, `concurrency-queue.ts`), and execution entry points (`index.ts`, `running-effects.ts`). A small sub-package `src/mq/index.ts` builds on top of `effect-mq` to define typed `Job` classes (e.g. `SendEmail`) with `Schema`-validated payloads, idempotency keys, metadata, retry/backoff defaults, and an `Effect.Layer` runner composed with `Worker.layer()` and `MemoryJobStore.layer`. There is no shared library code — every file is independently runnable via `bun packages/lab/src/<file>.ts` from the repository root, and files may execute effects immediately upon import.
