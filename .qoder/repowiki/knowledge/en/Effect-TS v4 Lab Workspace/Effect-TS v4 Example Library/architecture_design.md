Each file under src/ is an independent Effect program (or small library) that imports from the `effect` package directly; there is no shared runtime wiring between them. Cross-cutting concerns are isolated per-file: platform-specific TCP adapters live in tcp-connection-*.ts and are composed by tcp-stream-engine.ts into a uniform TcpStream service consumed by line-framing.ts's Cedro client, while concurrency_primitives, control_flow_operators, and error_result_utilities remain self-contained examples. The top-level src/index.ts is a minimal entry point that runs a single Effect via Effect.runSync.
