Three independent example scripts under `src/`, each a self-contained Effect program that imports primitives from the `effect` package and runs via `Effect.runPromise`. `concurrency-deferred.ts` shows one-shot value sharing between fibers using `Deferred.make/succeed/fail/await/poll` with `ForkChild` and `Fiber.joinAll`. `concurrency-pubsub.ts` demonstrates multi-producer/multi-consumer messaging via `PubSub.bounded/dropping/sliding/unbounded`, including subscription lifecycles managed by `Effect.scoped` and stream conversion through `Stream.fromPubSub`. `concurrency-queue.ts` illustrates backpressured channels via `Queue.bounded/dropping/sliding/unbounded`, covering offer/take blocking, shutdown semantics, and `Queue.await` for cooperative termination. All three files are leaf examples with no cross-file dependencies; they share only the external `effect` library as their runtime.
