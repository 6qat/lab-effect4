Each file is a standalone example script (not a library) that imports from the `effect` package and runs its program via `Effect.runPromise`, `Effect.runFork`, or `Effect.runSync`. The module groups examples by operator family: `control-flow-if.ts` shows `if` in generators and `pipe` chains; `control-flow-when.ts` covers `Effect.when` with Option/Result patterns; `control-flow-foreach.ts` and `control-flow-loop.ts` demonstrate `Effect.forEach` versus imperative `while` loops inside `Effect.gen`; `control-flow-zip.ts` shows `Effect.zip` / `Effect.zipWith` for concurrent composition; `control-flow-iterate.ts` illustrates iterative state mutation in generators; `control-flow-operators.ts` aggregates `Effect.all` over arrays/structs/records and a tagged-error example. There are no internal dependencies between these files — they are independent runnable demos.
