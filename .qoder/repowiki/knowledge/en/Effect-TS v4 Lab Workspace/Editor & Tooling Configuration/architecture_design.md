Two independent configuration areas coexist at the repository root: `.kilo/` holds Kilo AI editor state — `kilo.jsonc` declares the schema endpoint for validation, `agent-manager.json` tracks active worktrees, sessions, and tab ordering (with a `worktrees/` directory and per-worktree subdirectories under `command/`), and `.gitignore` excludes generated state. `.github/workflows/ci.yml` is a single GitHub Actions workflow named `CI` that triggers on pushes to `master` and all pull requests; it provisions an Ubuntu 24.04 runner, installs pnpm 11.21.0 and Bun 1.4.1, runs `pnpm install --frozen-lockfile`, then executes four sequential steps — TypeScript typecheck via `bun x tsc --noEmit`, unit tests via `bun test`, linting via `bun run lint`, and formatting checks via `bun x biome format ./src`. There is no dependency between the two areas; the CI pipeline operates on the source tree independently of the editor state.
