The root acts as a flat pnpm workspace (pnpm-workspace.yaml) with a single package.json declaring shared devDependencies (Biome, TypeScript, @effect/language-service) and runtime dependencies (@effect/platform-bun, @effect/platform-node, effect, effect-mq). All child modules — src_library (Effect examples), agent_skills (Markdown skills), docs_and_research (ADRs, research notes, Zed sync script), and editor_and_tooling_config (Kilo AI + GitHub Actions CI) — share the same tsconfig.json strictness settings, module resolution (nodenext/esnext), and lint/format pipeline. docker-compose.yml provisions a Redis service used by networking/concurrency examples in src_library, while scripts/sync-zed-prompts.mjs (invoked via `bun run sync-prompts`) bridges docs_and_research into the editor config. There is no cross-child code import; children are coordinated only through these shared tooling configs and the top-level scripts.
