Three-file internal split with a clear dependency direction: `tcp-connection-common.ts` defines shared types (`TcpStreamShape`, `ConnectionConfigShape`, `TcpStreamError`, `ConnectionConfig`) and validation helpers; `tcp-stream-engine.ts` builds the protocol-agnostic engine on top of a private `ColdAdapter` callback contract (`TcpStreamEngineAdapterEvent` + emit disposition) and exposes `makeTcpStreamEngine`, `withConnectTimeout`, `makeTcpStream`, and `TcpStreamLayer`; `tcp-connection-platform.ts` implements the concrete adapter using `@effect/platform-bun` (`BunSocket`) and Node's `tls.connect`, then wires it into the engine via `makeTcpStreamEngine(adapter)` and re-exports the public `TcpStreamPlatformLive` convenience layer. The engine owns connection lifecycle (connecting → ready → closed), an unbounded `Queue` bridging raw socket events to an `Effect.Stream`, a `Semaphore` serializing writes, and optional exponential+jittered retry via `Schedule`. TLS is handled by wrapping `tls.TLSSocket` in an `Effect.callback` and converting it to a `Socket.Socket` through `BunSocket.fromDuplex`.
