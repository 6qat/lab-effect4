Three layers are stacked inside one package: `tcp-stream-engine` defines the platform-agnostic `TcpStream` service contract; `platform_adapters` (`tcp-connection-bun.ts`, `tcp-connection-nodejs.ts`) implement it via `@effect/platform-bun` and `@effect/platform-node`; `protocol_layer` (`cedro-protocol.ts`, `line-framing.ts`) builds the Cedro command/subscription protocol on top of the shared `TcpStream` abstraction. The package root re-exports the Bun adapter as the default entry point while keeping Node.js and common contracts importable directly, so consumers can target either runtime without changing protocol code. Tests live alongside each layer and are run via `bun test ./src`.
