Each skill is a self-contained sub-directory under `.agents/skills/<skill>/` with a uniform layout: a `SKILL.md` entry point containing YAML frontmatter (`name`, `description`, optional `disable-model-invocation`) plus procedural instructions, and an optional sibling `agents/openai.yaml` declaring `interface.display_name`, `short_description`, and `policy.allow_implicit_invocation`. `ask-matt/SKILL.md` is the central router defining the main idea→ship flow, on-ramps (triage, diagnosing-bugs, wayfinder), vocabulary layer (domain-modeling, codebase-design), and standalone skills; other skills reference each other by path like `/grill-with-docs`, `/implement`, `/tdd`. Some skills ship executable artifacts — `wizard/template.sh` is a generated bash wizard split into a shared library section above a marker comment and an author-editable STAGES section below, and `diagnosing-bugs/scripts/hitl-loop.template.sh` provides a human-in-the-loop reproduction loop. `caveman-compress/` is the only Python package, exposing a CLI via `scripts/cli.py` that resolves its own package path at runtime so it works when invoked as a script or installed package. Dependency direction is one-way: skills are invoked by name from the router or from AGENTS.md pointers; there is no runtime framework, just Markdown consumed by the agent platform.
