The root acts as an orchestrator rather than containing application code: `package.json` declares a Bun workspaces setup under `packages/*`, so `packages/lab` (Effect v4 examples) and `packages/tcp` (typed TCP client) are installed and versioned together. The root `tsconfig.json` extends `tsconfig.base.json` and explicitly includes only `packages/lab/src/**/*.ts` and `packages/tcp/src/**/*.ts`, making TypeScript compilation a workspace-wide gate. Root scripts (`test`, `typecheck`, `format`, `format:check`) delegate to every child via `bun run --workspaces <script>`, while `biome lint .` runs once at the root against all packages. Cross-cutting concerns live outside the code children: `.github/` holds the CI pipeline, `.kilo/` configures Kilo AI, `.zed/` is synced from `docs_and_research` via `scripts/sync-zed-prompts.mjs`, and `.agents/` consumes the Markdown skills from `agent_skills`. A workspace-level `overrides` field pins `@effect/platform-node-shared` to `4.0.0-rc.112` so both packages stay on the same Effect v4 release candidate, and `docker-compose.yml` provides Redis for the lab's job-queue experiments.
