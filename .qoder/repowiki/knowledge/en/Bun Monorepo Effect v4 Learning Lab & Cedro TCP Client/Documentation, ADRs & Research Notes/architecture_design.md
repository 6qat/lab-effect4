Pure documentation plus a single Node.js utility — no application code. Three top-level sub-trees: `docs/adr/` contains numbered ADRs following the standard ADRC format (status, considered options, rationale); `docs/agents/` documents how engineering agents should consume repo context (domain glossary, issue-tracker labels, triage conventions); `docs/research/` holds exploratory notes on Bun TCP, DTC protocol, and Effect v3 vs v4 platform differences. `scripts/sync-zed-prompts.mjs` is an ESM Node script (`import.meta.url`, `node:fs`) that scans `.agents/skills` and `.agent/skills` for `SKILL.md` files and mirrors them under `.zed/prompts/*.md` and `.zed/skills/<name>/` (symlink with `fs.cpSync` fallback), enabling Zed slash commands to pick up project skills without duplicating content.
